ABOUT THIS RELEASE
------------------
Version 1.0 is the first public release of the Naval Architecture Engineering
Suite. It is a free, standalone desktop application for naval architects and
marine engineers, covering the essential calculations of early-stage ship design
in a single, connected tool with a unified dark navy / gold interface.

The suite was developed and is dedicated to the belief that professional
engineering tools should be freely accessible to every engineer, student, and
researcher worldwide.

NEW FEATURES IN VERSION 1.0 (ALL NEW - INITIAL RELEASE)
---------------------------------------------------------
  - Full 14-module connected suite in a single WPF desktop application
  - Dark navy / gold palette throughout (Helvetica-equivalent fonts)
  - 3D hull preview with real-time heel slider and pop-out window
  - Parametric Lines Plan with three views (Body Plan, Sheer, Half-Breadth),
    21 stations, lines-only drafting style (gold waterlines / blue stations)
  - PDF export with per-section checkboxes and paper size selector
  - 50-engine machinery database with SFOC curves
  - Window position and size persist between sessions
  - Runs fully offline - no internet connection required
  - No registration, no account, no telemetry


KNOWN LIMITATIONS IN VERSION 1.0
---------------------------------
  - No project save / load. All inputs are session-only and must be
    re-entered each time the application is launched.

  - Hull geometry is parametric (power-law sections). It is a visual aid
    and teaching tool, not a production lofting system.

  - PDF charts are rasterised (PNG embedded). Vector PDF not supported.

  - Resistance prediction uses Holtrop-Mennen regression. Applicability
    is limited to conventional monohull displacement vessels.

  - Damage stability uses a simplified SOLAS II-1 teaching model, not a
    full probabilistic flooding simulation.

  - LNG heat ingress uses a lumped single-zone U*A*DT model.

  - No import of external hull offsets or CAD geometry.

  - No multi-language support. Interface language is English only.

WHAT IS COMING IN VERSION 2
--------------------------------------------------------------------------------

The following features are planned for Version 2 (target: 2027):

  PROJECT SAVE / LOAD
    - Save and reload complete vessel projects to/from file (.nasp format)
    - Recent projects list on startup

  HULL GEOMETRY
    - Import of offset tables (CSV / Excel format)
    - Improved body plan with fairing controls
    - Export of offset table to Excel

  CALCULATIONS
    - Bonjean curves and sectional area curve
    - Trim and stability with multiple tanks and loading items
    - Free surface correction per compartment
    - MARPOL Annex I simplified Oil Record Book reference
    - Propeller design (B-series and Ka-series open water charts)
    - Seakeeping response (RAO-based significant motion estimates)

  REPORTING
    - Vector PDF output
    - Excel calculation summary export
    - Multi-page title block with company logo support

  PLATFORM
    - Installer with automatic .NET 8 detection and download
    - Auto-update notification
    - Optional dark / light theme toggle

  MODULES (NEW)
    - Mooring and anchor line tension (simplified catenary)
    - Fire safety (SOLAS Ch.II-2 zone concept reference)
    - Class society scantling reference (IACS Common Structural Rules)

Suggestions and feature requests are welcome via LinkedIn.
